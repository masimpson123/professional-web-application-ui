  1. Create an account or sign in

    Firebase Auth issues a signed ID token to the browser.

  2. Call the protected API

    The Spring service verifies the bearer token before returning weather data.

  3. Request the advanced usage claim

    The service adds a custom claim to your account. That invalidates your current token, so you’ll be signed out.

  4. Sign in again and call the advanced API

    Your new token carries the claim, which the advanced endpoint requires.
